# 빛을 따라, 파리 — Orsay & Eiffel

오르세에서 촬영한 회화 사진 53장과 에펠탑 사진 1장으로 만든 한국어 개인 감상 사이트.
루브르 참고 프로젝트의 목록 → 상세 감상 구조를 이어가며, 개별 해설과 검색, 분류, 해설 보기, 반응형 화면을 추가했습니다.

## 열기

`index.html`을 브라우저로 열면 됩니다. 설치나 빌드 없이 작동합니다.
HTTP 미리보기를 사용하려면 이 폴더에서 아래 명령을 실행한 후 http://localhost:4173 을 여세요.

```sh
python3 -m http.server 4173
```

외부 글꼴은 Google Fonts에서 받으며, 연결되지 않으면 시스템 글꼴로 표시합니다.

## GitHub Pages 배포

GitHub CLI(`gh`), Git, Python 3, curl이 있는 일반 터미널에서 실행합니다.
기본 대상은 공개 저장소 `pathcosmos/some-orsay-paintings-and-latoureiffel`입니다.

```sh
bash scripts/deploy-github-pages.sh
```

스크립트는 현재 GitHub 로그인을 확인하고, 로컬 커밋과 공개 저장소 생성·업로드 후 `main` 브랜치의 루트를 GitHub Pages로 설정합니다. 해당 커밋의 배포 성공과 사이트 HTTP 응답까지 확인한 후 실제 주소를 출력합니다. 로그인 요청이 나오면 `gh auth login -h github.com`으로 로그인한 뒤 다시 실행합니다.

HEIC 원본 54장과 JPG·PNG·웹용·썸네일 변환본을 모두 공개합니다. `.gitignore`는 사이트와 사진, 변환·배포 도구만 추적하며 로컬 조사 기록과 브라우저·편집기 상태는 제외합니다. `.nojekyll`로 별도의 Jekyll 변환 없이 정적 파일을 제공합니다.

## 감상 기능

- 회화 53장 갤러리, 작가·작품·연도 검색, 분야별 필터
- 갤러리 보기와 해설 보기 전환
- 전체 화면 상세 감상, 작품 해설과 감상 포인트, 참고 자료 링크
- 작품 정보 표: 원제, 제작, 재료, 크기, 소장번호, 취득, 전시실(오르세 소장품 기록 기준)과 소장 경위를 담은 작품 해설
- 이전·다음, 키보드 좌우 화살표, 모바일 좌우 넘기기, 사진 확대. 번호와 넘기기는 에펠탑을 포함한 전체 순서이며, 하단 썸네일은 현재 사진만 강조하고 나머지는 어둡게 표시합니다
- 상세 화면의 사진을 누르면 전체 화면 모달로 크게 보이고, 이전·다음으로 넘기거나 눌러서 닫을 수 있습니다
- 현재 사진의 주소 복사와 `#photo=IMG_1298` 형태의 직접 링크
- PC에서는 사진과 해설을 나란히, 모바일에서는 위아래로 배치
- 네이티브 dialog의 포커스 관리, Escape 닫기, 포커스 표시, 모션 감소 설정 지원
- 에펠탑 별도 해설: 만국박람회, 설계 참여자, 구조를 보는 방법

## 사진 파일

- `IMG_*.heic`: 원본 54장, 변경하지 않음
- `lossless/`: 원본 해상도의 PNG 54장. 디코딩한 RGB 픽셀을 추가 손실 압축 없이 보관
- `jpg/`: 원본 해상도, JPEG 품질 100으로 저장한 54장
- `web/`: 긴 변 최대 2000px, JPEG 품질 83
- `thumbs/`: 긴 변 최대 600px, JPEG 품질 75. 목록의 JPG 대체 이미지
- `responsive/`: 너비 160·320·480·800·1200px, WebP 품질 78. 목록·첫 화면·에펠탑 사진은 화면 크기와 픽셀 밀도에 따라 선택하며, 상세 미리보기 띠는 160px 사용
- `data/photo-map.csv`: 원본과 변환본, 작품 정보, 참고 자료의 대응표
- `data/catalog.json`: 작품 정보의 JSON 사본
- `details.js`: 작품별 상세 정보(원제, 제작, 재료, 크기, 소장번호, 취득, 전시실, 해설, 출처). 오르세 공식 소장품 기록 기준

**JPEG는 품질 100이어도 손실 압축입니다.** PNG가 이미 HEIC에 있는 정보를 복원하는 것은 아니며, HEIC를 디코딩한 이후의 추가 손실을 피하는 방식입니다. HEIC 원본도 계속 보존합니다.

원본의 ICC 색상 프로필을 추출하여 PNG와 원본 크기 JPG에 연결했습니다. 웹용 이미지와 썸네일은 sRGB로 색 변환합니다. 원본 EXIF 전체가 변환본에 복사되지는 않으므로 촬영 메타데이터가 필요한 경우 HEIC를 사용하세요.

### 다시 변환하기

macOS `sips`, FFmpeg, `cwebp`가 필요합니다. 기본 Apple HEIC 디코더가 검은 이미지를 출력하는 현상이 있어, FFmpeg로 먼저 PNG를 디코딩합니다.

```sh
python3 scripts/convert-photos.py
```

기존 PNG를 재사용하며 색상 프로필과 JPEG를 다시 생성하려면:

```sh
python3 scripts/convert-photos.py --reuse-png
```

기존 PNG에서 반응형 WebP만 생성하려면:

```sh
python3 scripts/responsive-photos.py
```

반응형 이미지는 원본 PNG를 sRGB로 변환한 뒤 생성합니다. 너비는 파일명의 숫자와 같으며, 현재 생성기는 1200px보다 작은 원본이 들어오면 오류를 알립니다. 목록의 지연 로딩을 유지하고, 갤러리·해설 보기 전환 시 `sizes`를 갱신합니다. 상세 화면과 확대 보기에는 기존 `web/` 이미지를 사용하며, 앞뒤 큰 사진 선로딩은 PC에서만 수행합니다(데이터 절약 모드·2G 연결 제외).

## 작품 정보와 확인 범위

작가와 작품은 사진 속 서명과 오르세 공식 소장품 기록(musee-orsay.fr), 공식 이미지와의 대조로 확인했습니다. `details.js`의 원제, 제작, 재료, 크기, 소장번호, 전시실은 해당 작품의 오르세 기록을 따르고, 해설은 오르세 기록의 해설과 소장 경위, 그리고 `refs`에 적은 자료를 근거로 새로 쓴 글입니다. `refs`에만 근거한 내용은 "알려져 있다", "전한다"처럼 표현했습니다. 전시실은 기록 기준이며 실제 배치는 바뀔 수 있습니다. `works.js`의 짧은 해설과 감상 포인트는 작품 정보와 사진에서 보이는 요소에 대한 자체 감상 제안을 함께 담습니다.

작품을 확인하지 못해 `provisional: true`로 표시한 사진은 현재 없습니다. 오르세 기록에서 "Anonyme"로 분류된 경우와 조사자가 아직 식별하지 못한 경우를 구분하며, 작자 미상으로 판단한 작품도 없습니다.

- IMG_1342: 사용자와 공식 이미지를 대조하여 에르네스트 에베르의 「당피에르 백작부인」(1880)으로 확인했습니다. 출처는 오르세 공식 에베르 갤러리입니다.
- IMG_1352: 사용자와 공식 이미지를 대조하여 「여인의 두상」(MNR 975)으로 식별했습니다. 공식 기록의 "토마 쿠튀르로 추정, 귀속 불확실"을 `attributionUncertain: true`로 별도 표시합니다. 이는 작품 자체를 식별하지 못한 상태와 다릅니다.
- IMG_1287: 사진 속 명판과 "Fantin, 82" 서명, 오르세 공식 기록으로 앙리 팡탱라투르의 「샤를로트 뒤부르」(1882)로 확인했습니다. 공식 이미지와 나란히 대조하지는 않았습니다.
- IMG_1288: 밀레의 서명 "J.F. Millet"과 장면 구성, 오르세 공식 기록으로 「만종」(1857–1859)으로 확인했습니다. 공식 이미지와 나란히 대조하지는 않았습니다.
- 두 작품의 전시실은 오르세 공식 작품 페이지(2026-10-20 확인)의 기록입니다. 「샤를로트 뒤부르」는 호실 번호 없이 "Rez-de-chaussée, Galerie Seine"으로만 안내됩니다.

## 검증 및 배포

JavaScript 구문, 카탈로그 항목과 파일 연결, 원본 대비 변환 해상도 및 프로필을 검사했습니다. 이번 환경에서는 브라우저가 연결되지 않았고 로컬 서버 바인딩도 권한 제한으로 차단되어 실제 PC·모바일 화면과 터치 동작은 검증하지 못했습니다.

정적 호스팅에 올릴 경우 index.html, styles.css, app.js, works.js, details.js, favicon.svg, web/, thumbs/, responsive/가 필요합니다. 상세 화면의 원본 다운로드를 제공하려면 jpg/, lossless/도 함께 올리세요. PNG와 원본 크기 JPG는 합계가 크므로 호스팅 용량 제한을 확인하세요.
